GAS 雲端資料同步魔法部署教學

透過 Google Sheets 作為永久資料庫，不僅完全免費，更不需要繁瑣的伺服器註冊！

💡 快速 3 步建立你的雲端存檔：
  1. 開啟一個全新的 Google 試算表 (Google Sheet)。
  2. 在選單點擊 「延伸模組」➔「Apps Script」。
  3. 將原本編輯器裡面的程式碼全部刪除，並貼上下方複製好的「魔法代碼」，接著點擊 「部署」➔「新增部署」➔「網頁應用程式」！
部署設定（非常關鍵）：
  • 執行身分： 選擇「我 (Me)」
  • 誰有權限存取： 選擇「任何人 (Anyone)」
Google Apps Script 原始碼 (.gs) 
function doGet() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getRange(1, 1, Math.max(sheet.getLastRow(), 1), 1).getValues();
  var payload = data.length > 0 && data[0][0] ? data[0][0] : "{}";
  return ContentService.createTextOutput(payload)
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var postData = e.postData.contents;
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  sheet.clear();
  sheet.getRange(1, 1).setValue(postData);
  return ContentService.createTextOutput(JSON.stringify({status: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}

⚠️ 部署完成後，將複製回來的「網頁應用程式網址」，直接寫死貼到程式碼最前方的 const GAS_URL = "您的網址" 變數中，大夥兒就能直接享有一鍵永久保存同步功能！
